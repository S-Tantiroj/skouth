**เรียงตามลำดับหน้าในเล่ม** เปิด Word ครั้งเดียวแล้วไล่ลงจากบนถึงล่าง

ที่มาของข้อความทั้งหมดคือ `2026-09-08-doc-corrections.md` — ไฟล์นี้เป็นฉบับใช้งาน

**วิธีใช้** ข้อความที่ต้องวางอยู่ระหว่าง `▼ วางข้อความนี้` กับ `▲ จบข้อความ`

**ก่อนเริ่ม** บันทึกสำเนาไฟล์ Word ไว้หนึ่งชุด (`ชื่อไฟล์-ก่อนแก้รอบ1.docx`)

## ☐ 6. หัวข้อ 2.3.3 — แทนทั้งหัวข้อ

ลบหัวข้อ "2.3.3) PostgreSQL…" เดิมทั้งหัวข้อ (ประมาณสามบรรทัด) แล้ววาง

▼ วางข้อความนี้

2.3.3) Supabase และ PostgreSQL (pgvector)

Supabase เป็นแพลตฟอร์มฐานข้อมูลที่สร้างบน PostgreSQL โดยเพิ่มระบบยืนยันตัวตน (Authentication), การจัดเก็บไฟล์ (Storage), REST API อัตโนมัติ และระบบควบคุมสิทธิ์ระดับแถว (Row Level Security) มาให้ในตัว โครงงานนี้ใช้ Supabase เป็นทั้งฐานข้อมูลและระบบจัดการผู้ใช้ จึงไม่ต้องเก็บรหัสผ่านเอง

ส่วนสำคัญที่สุดต่อโครงงานนี้คือ extension pgvector ซึ่งเพิ่มชนิดข้อมูล vector ให้ PostgreSQL ทำให้เก็บเวกเตอร์ความหมาย (Embedding) ขนาด 768 มิติไว้ในตารางเดียวกับข้อมูลปกติได้ และค้นหาด้วยความใกล้เคียงเชิงโคไซน์ผ่านตัวดำเนินการ <=> ได้ในคำสั่ง SQL เดียว จุดนี้คือสิ่งที่ทำให้สถาปัตยกรรม RAG ในหัวข้อ 2.3.5 ทำงานได้จริงโดยไม่ต้องติดตั้งฐานข้อมูลเวกเตอร์แยกอีกตัว

ข้อมูลผู้สมัครและข้อมูลตำแหน่งงานถูก Embedding ด้วยโมเดลเดียวกันและจำนวนมิติเดียวกัน จึงอยู่ใน "ปริภูมิเวกเตอร์" เดียวกัน ทำให้เปรียบเทียบข้ามกันได้โดยตรง — เป็นเงื่อนไขที่ทำให้การจับคู่ผู้สมัครกับตำแหน่งงานเกิดขึ้นได้

▲ จบข้อความ

## ☐ 10. ตารางที่ 3-6 (Users) — ลบแถว password + เพิ่มหมายเหตุ

**ลบแถว** `password | Varchar(255) | รหัสผ่านที่ผ่านการเข้ารหัส`

**เพิ่มหมายเหตุใต้ตาราง**

▼ วางข้อความนี้

หมายเหตุ: ระบบไม่เก็บรหัสผ่านไว้เอง การยืนยันตัวตนทั้งหมดจัดการโดย Supabase Auth ซึ่งเก็บรหัสผ่านที่ผ่านการแฮชไว้ในสคีมา auth แยกต่างหาก ตาราง profiles เก็บเฉพาะข้อมูลที่แอปพลิเคชันต้องใช้ (บทบาทและการตั้งค่า) และผูกกับผู้ใช้ผ่าน id ที่เป็นค่าเดียวกับ auth.users.id การออกแบบเช่นนี้ลดความเสี่ยงด้านความปลอดภัย เพราะรหัสผ่านไม่เคยผ่านโค้ดของโครงงานเลย

▲ จบข้อความ

> **ตารางทั้งตารางจะถูกแทนในรอบที่ 3** ด้วยชุดจริงจาก `2026-09-08-data-dictionary.md`
> รอบนี้แค่เอาคอลัมน์ `password` ออกก่อน เพราะเป็นจุดที่กรรมการถามได้ทันที
